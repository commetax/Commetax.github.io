# Commetax — site inicial

Site estático responsivo feito com HTML, CSS e JavaScript, preparado para GitHub Pages.

## Publicar em https://commetax.github.io

1. Crie/entre numa conta GitHub cujo nome de usuário seja `commetax` (se estiver disponível).
2. Crie um repositório público chamado exatamente `commetax.github.io`.
3. Envie `index.html`, `style.css` e `script.js` para a raiz do repositório.
4. Em Settings → Pages, selecione “Deploy from a branch”, branch `main` e pasta `/(root)`, e salve.
5. Aguarde alguns minutos e visite `https://commetax.github.io`.

Se o nome de usuário `commetax` não estiver disponível, escolha outro nome de usuário e crie um repositório de projeto; o endereço será diferente (por exemplo, `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`).

## Antes de divulgar
- A seção de contato usa um endereço de e-mail ilustrativo (`contato@commetax.com.br`); altere para um e-mail real.
- As duas imagens decorativas são carregadas do Unsplash e precisam de internet para aparecer.
- Este site é uma apresentação inicial. Login, cadastro e funcionalidades de rede social ainda não estão implementados.
